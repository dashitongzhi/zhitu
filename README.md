# 职途AI

场景驱动的求职全流程工具，围绕「写简历、练面试、追投递」三个高频求职场景设计。

## 三大核心模块

| 模块 | 说明 |
|------|------|
| 简历实验室 | 所见即所得的简历编辑器，支持模块化管理、实时预览、AI 驱动的 JD 匹配优化 |
| 面试训练场 | 模拟真实面试环境的语音交互训练，AI 面试官实时提问，多维度评分复盘 |
| 投递看板 | 飞书式多维表格追踪投递全流程，记录面试轮次、HR 反馈与当前状态 |

三个模块以简历版本和投递记录为纽带形成闭环：简历写完直接关联投递 → 投递后针对岗位练习面试 → 面试结果反馈到投递记录。数据在模块间自动流转，用户无需重复输入。

## 产品需求文档

完整的 PRD 文档（含可交互原型 Demo）在 `docs/` 目录下，浏览器直接打开即可查看：

```
docs/jobhunter-prd.html
```

文档包含：
- 需求背景与目标用户画像
- 三大模块的交互原型 Demo（可直接点击体验）
- 页面布局、业务逻辑、字段规则、状态转换的详细说明
- 模块间协同关系与全局信息架构

## 技术栈

技术栈选型由开发团队根据项目需求自行决定，PRD 不限定具体技术方案。

## 开发协作

- 主分支 `main` 只存放经过测试的稳定代码
- 每个功能在独立的 `feature/` 分支上开发
- 提交 PR 后由团队成员 review 并测试，通过后合并到 `main`
