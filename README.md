## 产品定位

面向应届生和初级求职者，解决求职过程中工具零散、信息不对称、缺乏沉浸式练习环境的痛点。产品以简历版本和投递记录为数据纽带，将三大核心模块串联成闭环：简历写完直接关联投递 → 投递后针对岗位练习面试 → 面试结果反馈到投递记录。数据在模块间自动流转，用户无需重复输入。

## 模块概览

| 模块 | 核心能力 | 差异化设计 |
|------|----------|------------|
| 登录与认证 | 邮箱密码 / GitHub OAuth / 手机验证码三种登录方式，数据隔离与跨设备同步 | — |
| 简历实验室 | 所见即所得编辑器，模块化管理、实时预览、AI 驱动的 JD 匹配优化 | **简历竞争力雷达** — 对标同岗位竞争者，告诉你排第几梯队 |
| 面试训练场 | 语音交互模拟面试，AI 面试官实时提问，多维度评分复盘 | **面试官画像库** — 众包匿名分享真实面试经历，消除信息不对称 |
| 投递看板 | 飞书式多维表格追踪投递全流程，记录面试轮次、HR 反馈与状态 | **求职策略洞察** — AI 分析投递数据，从「记账本」变「决策助手」 |

三个差异化设计构成产品的核心壁垒，区别于市面上同质化的 AI 求职工具。

## 开发协作

详细的协作规范见 [CONTRIBUTING.md](CONTRIBUTING.md)，核心要点：

- `main` 分支只存放经过测试的稳定代码
- 每个功能在独立的 `feature/` 分支上开发（如 `feature/resume-preview`）
- 提交 PR 后由团队成员 review 并本地测试，通过后合并到 `main`
- 数据库 schema 变更需提前沟通，避免合并冲突
- 每日开工前 `git pull origin main` 保持本地代码同步
